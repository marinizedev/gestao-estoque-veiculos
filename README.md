# Gestão de Estoque de Veículos

Sistema CRUD para gestão de estoque de veículos, desenvolvido com Java,
Spring Boot e MySQL.

## Objetivo

Facilitar o cadastro, a consulta, a atualização e o controle da situação
dos veículos de uma concessionária.

## Funcionalidades

- Cadastro de marcas, modelos e veículos
- Consulta e filtros de veículos
- Atualização dos dados do estoque
- Controle de situação: disponível, vendido ou descontinuado
- Remoção de cadastros incorretos ou duplicados

## Tecnologias

- Java
- Spring Boot
- MySQL
- Maven
